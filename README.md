# SmartCare — Clinical Call and Chat for Home Healthcare

**Home healthcare, coordinated in real time.** SmartCare is a home healthcare provider in Riyadh, and this is the clinical call and chat platform behind its operations: patients, care coordinators and clinicians talk in real time, and every request is tracked from the first message to the visit.

🔗 Live product: **[smartcare.med.sa](https://smartcare.med.sa)**

> This repository is a project showcase. It contains documentation only — the production source code is private.

---

## Overview

Home healthcare runs on coordination. A physiotherapy session, a home lab test or a nursing visit is only as good as the conversation that schedules it and the follow-up after it.

SmartCare's platform handles that conversation: clinical chat and call handling for a service that serves **500+ medical clients**, with the real-time infrastructure that keeps everyone on the same page.

## What the platform supports

**Clinical chat**
- Real-time conversations between patients, care coordinators and clinicians.
- Message history tied to the patient and the case, so context travels with the conversation.

**Call handling**
- Clinical call flows coordinated inside the same system as chat, so a call and its follow-up live in one record.

**Operations**
- Requests and visits tracked from the first message to completion.
- Notifications that reach the right person as things change.
- A backend built for the operational team that runs the day-to-day.

**Services served**
Physiotherapy, lymphatic massage, home lab tests, nursing visits, home companionship and doctor visits — the services offered through smartcare.med.sa.
